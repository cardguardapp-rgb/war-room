Create a personal job search and application assistant web app. This is a single-user app for me only — no multi-user auth, but add a simple 4-digit PIN gate on load (PIN stored as an environment variable APP_PIN).

STACK:
- Node.js + Express backend
- React frontend built with Vite
- Tailwind CSS, mobile-first (I will use this mostly on my phone — design for a 390px viewport first, then scale up)
- SQLite via better-sqlite3 for storage
- File storage in a local /uploads directory

STRUCTURE — create these pages with working navigation (bottom tab bar on mobile, sidebar on desktop):
1. "Profile" — where I upload my base resume (.docx) and manage my professional details
2. "Jobs" — list of job postings I've added, each with status (New / Tailoring / Ready / Applied)
3. "Job Detail" — view a single job: posting text, tailored resume, cover letters, downloads
4. "Discover" — search for roles on the web (leave as placeholder UI for now)

BACKEND SKELETON:
- Express routes scaffolded for: resume upload, job creation (by URL or pasted text), tailoring, document generation, and discovery search — stub implementations returning placeholder JSON are fine for now
- SQLite schema: 
  - profile (id, resume_filename, resume_json, style_map_json, extra_answers_json, updated_at)
  - jobs (id, title, company, source_url, posting_text, status, created_at)
  - documents (id, job_id, type [resume|cover_letter|cover_letter_plain|cover_note], content_json, docx_path, pdf_path, created_at)
  - qa_log (id, job_id, question, answer, created_at)
- Environment variables: ANTHROPIC_API_KEY, TAVILY_API_KEY, APP_PIN — read from Replit Secrets, never hardcoded

CONVENTIONS:
- Australian English spelling everywhere in UI text (e.g. "tailored", "organise", "colour")
- Clean, minimal UI — generous tap targets, no tiny buttons
- Create a CLAUDE.md file in the project root documenting: the stack, the database schema, the folder structure, the purpose of each page, and the rule that all AI-generated content must use Australian English and must never fabricate experience. Future development will be done via Claude Code over SSH, so keep CLAUDE.md updated as the source of truth.

Do NOT implement any AI logic yet — just the scaffold, navigation, PIN gate, database, and stubbed routes. Confirm the app runs and all four pages render on mobile width.
